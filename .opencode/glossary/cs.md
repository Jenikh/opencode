## Do Not Translate (Locale Additions)

- `OpenCode` (preserve casing in prose; keep `opencode` only in commands, package names, paths, or code)
- `OpenCode Desktop`
- `CLI`, `TUI`, `MCP`, `OAuth`
- Agent names: `build`, `plan`, `general`
- Commands, flags, environment variables, file paths, and code literals (keep exactly as written)

## Guidance

- Prefer natural Czech phrasing over literal translations.
- Keep technical artifacts exactly as written: commands, flags, URLs, model IDs, file paths, and code.
- Preserve product names and protocol names.
- Keep agent names unchanged.
- Use consistent terminology throughout the documentation.
- Prefer formal Czech ("vy") in user-facing documentation.

## Avoid

- Avoid translating product and protocol names that are fixed identifiers.
- Avoid mixing multiple Czech terms for the same recurring UI action.
- Avoid literal translations that sound unnatural in Czech technical documentation.
